Die Levenshtein-Distanz ist die minimale Anzahl einfügender, löschender und ersetzender Operationen um die erste Zeichenkette in die zweite umzuwandeln.


| **Wort** | **Operation** | **Anzahl** |
| -------- | ------------- | ---------- |
| Haus     | Ausgangswort  | 0          |
| Hau      | Löschung      | 1          |
| Hauser   | Einfügung     | 2          |
| Hans     | Ersetzung     | 1          |
|          |               |            |
| Haaus    | Einfügung     | 1          |
